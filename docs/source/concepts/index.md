# Concepts

no knowledge of TLS or of this project. Read them in order:

1. [TLS cipher suites and code points](cipher-suites.md) explains what a
   cipher suite is, what a code point is, and why one suite has many
   names.
2. [How libraries, versions and suites relate](data-model.md) explains
   how this project stores that knowledge: libraries, versions, suites,
   membership, the catalogue and the status of each version.
